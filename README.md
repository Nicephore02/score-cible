# Score Cible — IELTS & TOEFL + Dossier Bourse (V3)

MVP statique responsive avec :
- diagnostic et objectif
- dashboard de progression
- 18 leçons
- XP et progression locale
- mini quiz
- coach de stratégies
- checklist dossier de bourse
- design mobile/desktop

## Important
Le site fonctionne sans serveur grâce à localStorage. Il ne contient pas de vrai compte utilisateur,
paiement, base de données ou clé API IA.

Pour une version commerciale complète, ajouter :
1. authentification
2. base de données
3. paiement/abonnement
4. backend pour l'IA
5. stockage sécurisé des fichiers
6. analytics et espace administrateur

## Déploiement
Option simple : héberger le contenu du dossier sur un hébergeur statique (Netlify, GitHub Pages, etc.).
Le fichier d'entrée est `index.html`.

## Vidéos
Le dossier `videos/` contient des vidéos MVP silencieuses à utiliser comme introductions visuelles.
Elles ne sont pas des cours narrés : ajouter une voix enregistrée ou une solution TTS séparément.
